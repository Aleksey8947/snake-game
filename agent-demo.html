🤖 Как работает агент автоматизации

Тот же принцип, что в n8n: запрос → обработка кодом → вызов внешнего сервиса → форматирование → ответ
// Нажмите «Запустить агента» — данные «пакетиком» пройдут по всем узлам, как в реальном workflow n8n.
// В последнем узле будет сделан НАСТОЯЩИЙ запрос к открытому API wttr.in (без ключей).
В интерфейсе n8n вы бы увидели то же самое: подсветку выполняемых узлов и JSON-данные на выходе каждого шага.
